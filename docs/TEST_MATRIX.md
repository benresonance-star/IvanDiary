## CI mapping

- **Web quality gates** (`web`): `npm ci`, `npm run typecheck`, `npm run lint`, `npm run test:coverage`, and `npm run build`.
- **iOS simulator build** (`ios`): `npm ci`, all 32 Swift package tests via `swift test --package-path packages/ApplePlatformServices`, `npm run cap:sync`, and an unsigned generic iOS Simulator build.
- CI compilation does not substitute for physical iPad acceptance and does not behavior-test app-target CloudKit calls.

## Swift test inventory

The 30 Apple audio tests cover completion/error contracts, recording state and finalization, managed-file trash behavior, native text editing, keyboard/voice transitions, provider selection, live partials, permission/error mapping, cancellation, interruption, and restart. Exact examples include `AppleAudioServicesTests.recordingTransitionsAndInterruptionRecovery()`, `AppleAudioServicesTests.nativeLiveVoiceReportsInterruptionAndCanRestart()`, and `AppleAudioServicesTests.trashRemovalCannotEscapeManagedAssetDirectories()`.

The 2 drawing tests are `AppleDrawingKitTests.NativeDrawingGesturePolicyTests/pencilDoesNotTriggerContentInteractions()` and `AppleDrawingKitTests.NativeDrawingGesturePolicyTests/drawingDoesNotWaitForContentInteractions()`.
